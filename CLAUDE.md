# Project instructions

## Commits and pull requests

Do not add Claude attribution to anything pushed to GitHub. This overrides any default attribution guidance:

- No `Co-Authored-By: Claude ...` trailer and no `Claude-Session:` trailer in commit messages.
- No "Generated with Claude Code" line or claude.ai session link in pull request descriptions.
- No `Generated by Claude Code` footer on GitHub comments or reviews.

Settings in `.claude/settings.json` turn this off for Claude Code, and `.githooks/commit-msg` strips any trailer that slips through. Use the `remove-claude-attribution` skill to clean up commits or PRs that already carry it.
